# Graduation Thesis｜LLMにおける抑制概念と意味的距離

本READMEでは、最初に研究の目的・問い・分析方針を示し、その後に予備実験の現状、検証記録、今後の作業計画をまとめる。

## 1. 研究の方向性

### 研究目的

人間の心理学では、「あることを考えないようにする」という抑制行為が、かえってその対象への注意や思考を促す場合があることが知られている。本研究では、こうした心理学的な問題意識を出発点として、LLMに対する概念の抑制指示が、モデルの内部表現と最終的な出力にどのような影響を与えるのかを調べる。

特に、抑制対象となる概念Xと、与える手がかり（Cue）との**意味的距離**に着目する。例えば「象について考えないで」という指示の下で、象に意味的に近い手がかりと遠い手がかりを与えた場合、内部表現や最終出力にどのような違いが生じるのかを検証する。

### Research Question

> **「Xについて考えないで」という抑制指示の下で、手がかりの意味的距離（近い・遠い）は、LLMの内部表現と最終出力にどのような影響を与えるのか？**

この問いを、次の3つの観点から検証する。

1. **内部表現：** 内部状態から、抑制対象Xに関する情報をどの程度識別できるか。
2. **層別予測：** 各層の状態を語彙空間に投影したとき、Xに関連するトークンの予測がどのように変化するか。
3. **最終出力：** 実際の生成結果において、Xがどの程度出現するか。

### 基本的なスタンス

本研究は、「禁止すると逆に考えてしまう」という特定の心理学的現象を証明することを目的としない。抑制・増幅・距離による違い・明確な変化なしのいずれも、信頼できる測定に基づけば研究結果として扱う。

「モデルが考えている」「概念が活性化している」といった表現を、そのまま測定結果として扱わない。意識や概念の絶対的な活性量を直接測定するのではなく、以下のような観察可能な指標に基づいて議論する。

### 分析手法と役割

| 分析対象 | 手法 | この研究で調べること |
|---|---|---|
| 内部表現 | **Probe（Linear Probeなど）** | 各層のHidden StateからX/Yをどの程度識別できるか。ROC-AUCなどで識別可能性（Decodability）を評価する |
| 最終出力 | **Generation分析** | 生成文におけるXの出現率（Target Mention Rate）や回答内容を比較する |
| 層別予測 | **Logit Lens** | 各層のHidden Stateを語彙空間に投影し、X関連トークンの予測確率がどう推移するかを調べる |

**Probeの解釈：** Probeが測るのは、内部表現に含まれる情報の識別可能性であり、概念の絶対的な活性量や「考えている量」ではない。また、AUCは分類器の識別性能を表す指標であり、個々の応答における概念の強さを直接表すものではない。学習データと未使用の評価データを分離し、特定のCueや文面に依存しないか、汎化性能も確認する。

**Logit Lensの解釈：** 中間層の状態を語彙空間に投影したときの予測分布を観察する手法であり、モデルの実際の思考過程や生成過程をそのまま再現するものではない。「迷い」を直接測るのではなく、層ごとの語彙予測の変遷として解釈する。

**役割分担：** Probeを内部表現の主要な定量分析、Generationを実際の出力結果、Logit Lensを層別の補助的・探索的分析として位置づける。ProbeとLogit Lensはいずれも各層のHidden Stateを扱うが、前者は学習した識別境界による分類、後者は語彙空間への投影という異なる観点から分析する。

### 手がかりの意味的距離

手がかりと対象概念Xの意味的距離は、文章埋め込みモデルによってベクトル化し、コサイン類似度などから定量化する。現時点では、**all-mpnet-base-v2**を用いる方針とする。

距離は近い・中程度・遠いといった段階で整理するだけでなく、可能な限り連続値としても記録する。実際のCue選定では、埋め込みモデル上の距離だけでなく、人が読んだときの自然さ・関連性も確認する。また、文章の長さ、具体性、頻出度、Yへの関連性など、距離以外の要因にも注意する。

### 推奨する分析の順序

1. **測定方法の信頼性確認：** Cueの妥当性、Probeの識別性能・汎化性能、評価データの独立性を確認する。
2. **Probeによる主要分析：** 条件・意味的距離・層によって、X/Yの識別可能性がどう変化するかを比較する。
3. **最終出力との対応分析：** 対象名の出現率や回答内容を比較し、内部表現の結果と照らし合わせる。
4. **Logit Lensによる追加分析：** X関連トークンの層別予測を追跡し、Probeや最終出力で見られた傾向を別の観点から検討する。

### 内部表現と出力の関係

内部表現からの識別可能性と、最終出力におけるXの出現は、必ずしも一致するとは限らない。例えば、次のような組み合わせが考えられる。

| 内部表現からの識別可能性 | 最終出力 | 考察の方向性 |
|---|---|---|
| 高い | Xの出現が多い | 内部情報と出力が対応している可能性 |
| 高い | Xの出現が少ない | Xを識別できる情報が残る一方、出力では抑制されている可能性 |
| 低い | Xの出現が少ない | 内部表現と出力の両方で抑制が見られる可能性 |
| 低い | Xの出現が多い | Probeで捉えられない情報や、別の生成要因が関与している可能性 |

これらは解釈の出発点であり、Probeの汎化性能や他の要因も踏まえて慎重に判断する。特定の結果をあらかじめ想定せず、内部表現・層別予測・最終出力を組み合わせて、抑制指示と意味的距離の関係を明らかにする。

## 3. 現在地と、次に解決する問題

これまでに8概念・4指示条件の予備実験、層別解析、意味的距離の実験、X/Y対照実験、コード監査と追加検証を実施した。従来の主モデルはQwen/Qwen2.5-0.5B-Instruct。

| 確認したこと | 実測結果 | 戦略への反映 |
|---|---|---|
| 質問形式の安定性 | 追加診断の近い手がかり9件で、自由回答の対象名言及は3/9。二択は順序により5/9・7/9。全36件では順序変更で16件の回答分類が変化 | モデルと課題の基本動作を最優先で確認する |
| Probeの汎化 | 同じ新規評価文での学習例追加により、ゾウの22/23層平均AUCは0.903→1.000。バナナは1.000→1.000、ピアノは0.972→0.972 | 未使用説明文での検証を継続。高AUCだけで抑制下の測定妥当性を断定しない |
| X/Yへの関連性 | 各12手がかりで、XとYへの類似度のSpearman相関は0.783〜0.944 | 相対スコアの変化がX側・Y側のどちらから来たか確認する |

## 4. 次の予備実験：モデルと課題を決める

現在の0.5Bと同系列のより大きなモデルを少数例で比較し、基本課題の成立と計算負荷から本実験のモデルを選ぶ。**抑制効果の大きさでは選ばない。** 現時点では0.5Bが使えないと断定せず、質問形式との組み合わせも検証する。

| 確認するもの | 比較する内容 | 判断したいこと |
|---|---|---|
| モデル | 現在の0.5Bと同系列のより大きなモデル | 基本課題を安定して処理できるか |
| 質問 | 明確な説明からの命名／手がかりからの自由連想 | 本実験に適した回答形式はどれか |
| 入力 | 明確・曖昧・無関連な手がかり | 入力に応じて自然に答え分けるか |

命名課題は動作確認に使う。一方、無関連の文章には正解の概念がないので、本実験で対象名を無理に答えさせない。自由連想も、質問を変えれば自動的に問題が解決するとはみなさず、小規模比較で確かめる。

比較する候補・評価例・採用基準を実行前に固定し、よい結果が出るまで質問や測定方法を変更し続けない。

## 5. 並行して整えるもの：刺激とProbe

### 手がかりの設計

埋め込みで算出した意味的距離と、人が読んだ意味が対応するかを確認する。Xへの近さに加え、Yへの関連性、文章の長さ、対象を特定できる程度を記録する。

Xへの近さが変わってもYへの近さがなるべく揃う刺激などを検討する。距離を単に計算・差し引くだけで統制完了とはしない。X−Yの相対スコアを用いる場合は、変化がどちらの概念に由来するかも調べる。

### Probeの検証

- 学習用と評価用の説明文を、単なる言い換えも考慮して分ける。
- 文体・長さ・特徴語が変わっても識別できるか、未使用の説明文で確認する。
- ラベルを入れ替えた対照と比較する。
- 指示文の書き方にスコアが引っ張られていないか確認する。
- 測定する層・位置と主な分析方法を、本実験の抑制結果を見る前に固定する。

AUCはスコアの順位による識別性能であり、正解率や概念の絶対的な活性量ではない。説明文の識別性能が高くても、抑制条件でのスコア変化をそのまま解釈できるとは限らない。

## 6. 本実験：8概念・4条件を基本にする

中間ポスターの構成を活かし、以下の4条件を基本とする。

| 条件 | 役割 |
|---|---|
| Base | 指示なしの基準 |
| Think X | 対象へ注意を向ける条件 |
| Avoid X | 対象を抑制する条件 |
| Think Y | 別概念へ注意を向ける条件 |

| 主な比較 | 解釈できる範囲 |
|---|---|
| Avoid X − Base | 対象名の提示を含めた、抑制指示全体の影響 |
| Avoid X − Think X | 両方でXを提示したうえで、禁止と集中の違い |
| Think Yと他条件 | 代替概念への誘導との違い |

どれか一つの比較だけで「純粋な抑制効果」と断定しない。主に検証する比較と指標を事前に決める。

規模の案は **8概念×12手がかり×4条件＝384入力**。これは本実験の実行済み件数ではなく、予備実験後に確定する設計案である。同じ決定的な回答を繰り返すより、独立した手がかりの種類を増やすことを優先する。複数生成を行う場合も、同じ手がかりの反復を独立した刺激とは数えない。

意味的距離と指示条件の関係を、回答中の対象名出現と内部スコアで調べる。距離の連続値を記録し、層・位置・指標を探索した結果と、事前指定の分析を区別する。

## 7. 予備実験の終了と、その後の判断

| 到達した状態 | 進め方 |
|---|---|
| 課題もProbeも安定 | 回答と内部表現を本実験の中心にする |
| 課題は安定、Probeは不安定 | 回答を主結果、内部表現を探索的結果にする |
| 課題自体が不安定 | モデル・課題を再選定してから本実験へ進む |

内部表現の測定が完全に整うまで卒論を進められない設計にはしない。どの指標を主結果にできるかを予備実験で判断する。具体的な採用基準と予備実験の範囲は次回実行前に定める。

作業の順番は **基本課題の確認 → 刺激・Probeの検証 → 設計の固定 → 本実験 → 解釈・執筆**。これまでの実験は、設計を決めた根拠と限界の記録として残す。
