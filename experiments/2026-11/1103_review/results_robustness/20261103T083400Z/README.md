## 結論

1. **元の設定での数値をほぼ再現した。** 元のv3効果−0.11016に対し、今回の元Probe・元指示・元書式・元CueでX/Yを平均した値は−0.11076。旧実行はFP16、今回はFP32であり、完全一致は要求しない。
2. **新しいCueでも同方向だった。** 同じ設定で新規CueのX/Y平均は−0.14158。各方向で8ペアすべて負。
3. **効果の大きさは文面に強く依存した。** 元の指示・元Probeでも、手がかりの前に`Context:`を付けると、元Cueの平均効果は−0.11076から−0.01565へ縮小。語彙・トークン位置・測定文脈が一緒に変わるため、そのどれが原因かは切り分けられていない。
4. **全設定で普遍的には成立しない。** 480設定中471設定で平均が負、9設定ではごく小さな正（最大+0.00265）。9設定すべての探索的区間は0を含む。設定同士は同じ8ペアを共有する感度分析であり、471回の独立した再現や成功率98%を意味しない。
5. **距離効果は引き続き未確立。** 元設定のv2を再現しても、単純回帰の区間は0をまたぐ。22層の長さ調整後だけを見ると区間は正だが、符号反転検定はp=0.08594、23/24層では区間が0をまたぐ。多条件・多層の探索もあるため「距離が効く」とはまだ結論しない。

## Probeの信頼性

- 元Probeの22/23層の説明文評価: 平均AUC **0.97049**、最小 **0.77778**。
- 学習説明を減らすと、一部Probeの評価が悪化。20構成×8ペア×2層=320評価のうち **36評価がAUC 0.75未満**。すべての学習構成が安定とは言えない。
- シャッフルラベルの22/23層の平均AUCは約 **0.483**。ただし、個別には0や1もあり、小さい評価セットでは高AUCだけを根拠にしない。
- 6種類の独立した説明文を2文型で評価している。12個の独立した意味的事例ではない。説明文・概念ペアの拡充は必要。
- 9つの正の設定の一部には、AUCを通過するProbeも含まれる。「不良Probeだけが原因」とは断定しない。

## 実行時の安全チェック修正

最初の追加実行は、手がかり前のHidden Stateを絶対差`1e-5`で検査するチェックが厳しすぎて停止した。T4 FP32では同じprefixでも全体の系列長により計算カーネルが変わり、微小差が生じる。

修正版では、**実際に入力されたprefixのtoken ID列のSHAが一致すること**を検査したうえで、絶対差1e-3以下かつ各層の相対差1e-5以下を要求する。差はCSVに保存し、越えたら停止。全4,608入力で通過し、実測最大絶対差は0.00035858、最大の層別相対差は0.0000033631。結果値のクリップや補正はしていない。

これは追加実験コードの検査基準の修正で、過去のv2/v3データは変更していない。丸め差を許容するテストと大きな差を拒否するテストを追加し、テスト計6件が通過。
