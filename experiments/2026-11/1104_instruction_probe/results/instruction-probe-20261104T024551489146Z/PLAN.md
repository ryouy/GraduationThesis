# 指示と手がかりに対するProbe感度（2026年11月4日・推論前固定）

状態：実行準備。Phiで特徴抽出・Probe学習を行う新しい実験。モデル推論は未実行。名前当ての改善はここで区切り、内部スコアの解釈可能性を診断する。

## 問いと限界

出力の命名正答率が低いことは、内部に概念情報がないことと同義ではない。今回は出力を生成せず、同じ手がかりで指示だけ変えたとき、Probeの識別スコアがどの程度変わるかを測る。

指示に対象名が出るだけでスコアが動くか、説明文が加わるとどう変わるかを調べる。指示だけの変化があっても、単なる字面の影響・通常の概念表現・注意の変化をこの実験だけで完全には区別できない。Probeスコアを「考えた量」「絶対的な活性」「純粋な抑制効果」とは呼ばない。

## 因子計画

3組：banana/apple、elephant/giraffe、piano/violin。正方向をX、負方向をYとした二値Probeを各組で学習する。全6概念・全8概念の一般性は主張しない。

| 指示条件 | テキスト例（X=elephant, Y=giraffe） |
|---|---|
| neutral | Read the context carefully. |
| mention_x | The topic word is elephant. |
| think_x | Think about elephant. |
| avoid_x | Do not think about elephant. |
| think_y | Think about giraffe. |

各指示に、X説明6文・Y説明6文・無関係6文・手がかりなし1件を交差。1組19文×5条件=95行、3組285行。無関係6文は各組で同じものを使う。手がかりなしは空文字でなく固定マーカー [No descriptive context.]。1つのマーカーを独立な複数試行と数えず、誤差棒・有意性を付けない。マーカー自体の影響も残る。

指示文の長さ・統語・単語位置は一致しない。mention_xは単純な対象名提示の参考であり、これとの差が字面の影響を完全に除いたものではない。think_xとavoid_xにはXが各1回登場するが、否定語追加等の違いは残る。

共通のuser形式：Instruction、Context、Give one short response about the context.。命名問題や候補一覧は追加せず、実際の回答も生成しない。毎入力で独立forwardし、前の入力の状態を持ち越さない。同一promptは一度だけ抽出して再利用する。

## PhiでProbeを再学習する

モデル：microsoft/Phi-3.5-mini-instruct、固定revision 2fe192450127e6a83f7441aef6e3ca586c338b77。FP16/SDPA・量子化なし・eval。systemはYou are a helpful assistant.。transformers4.57.6、seed42。Phi内蔵実装を使用し、remote custom codeは実行しない。

既存training_design.csvの命名用データから、単独の対象名と重複フレームを除く。各概念15文、6概念で90文。全てneutralの共通形式で入力する。Probe学習時にThink/Avoidのラベルや今回の条件スコアは使わない。旧Qwenの重みをPhiへ流用しない。

評価説明は1103_fresh_check/items.jsonのX/Y各6文・無関係6文。Probe学習文との完全一致・対象名漏洩を事前検査する。ただし特徴語や近い言い換えは共有し、説明の独立性・一意性を保証しない。これらは命名の比較では既出の文であり、モデル選定後の最終ホールドアウトとは呼ばない。

主測定：Phi32層のうちhidden_states[31]、assistantの生成プレフィックス最終token（回答生成前）。追加測定は層16/24/32と、説明文最後の文字を含むtoken。hidden_states[0]は埋め込みであるため層番号の取り違えに注意する。主層・主位置は出力を見て変更しない。マーカー条件のcontext_endはマーカー末尾であり、説明文と同一の語彙位置ではない。

各組30学習文にStandardScaler＋LogisticRegression(C=0.1、liblinear、max_iter2000)。層4×位置2×組3=24Probe。スケーラーも学習文だけでfit。特徴はFP16で保存し、学習・再計算はfloat64で統一。marginの大きさはモデルの絶対活性ではない。見やすさのため学習margin平均と標準偏差で標準化するが、異なるProbe間の絶対量比較を保証しない。

neutralのX/Y評価12文でAUCを計算。主層・主位置のみ、説明文単位の学習ラベルを100回シャッフルした対照と比較する。各組15/15のバランスを保つ。AUC>=0.8かつシャッフル95パーセンタイルを厳密に超える場合のみcalibration_okとする。小標本の探索的な警告基準であり、本実験採用判定や有意性検定ではない。シャッフルでも高AUCが出る場合は、この評価集合では十分に区別できないという警告であり、概念情報が存在しない証明とはしない。基準不通過の組のスコアを概念変化の証拠にしない。

## 記録と解釈

- 各指示のX/Y識別AUC（各12文）を併記し、neutralで良いことだけから指示条件でも妥当と断定しない。
- 指示だけの感度：emptyで各条件−neutral（各1入力の記述的比較）。
- 手がかりの追加：同じ指示内で各cue−empty。長さ・語彙の追加も含み、純粋な意味効果ではない。
- 同じcueで指示の差：各条件−neutral。語提示を含む指示全体の差。
- 差の差：上記cue−emptyの差がneutralからどれだけ変わったか。探索的な交互作用として記録。

グラフは主位置・主層を事前指定し、説明文ごとの点と平均を描く。361unique promptのforward（90学習＋271診断）、285実験行、2280スコア。繰り返し生成や独立な285概念とは数えない。SEMやp値で結論を強めず、他層・位置は補助として残す。高AUCでも抑制下の測定妥当性を全面的に証明しない。モデルの採用はこの実験では判断しない。
