# 10概念Pre-main：比較概念Yへの距離を考慮した再分析

2026-11-25。探索的な事後分析。新規Qwen推論は行っていない。

## 方法

[Pre-mainの固定結果](../1124_pre_main_experiment/results/20261124_pre_main_v1/)の cue_selected.csv、distance_statistics.csv、sensitivity_correlations.csv、probe_scores.csv を利用。各概念・条件の関連20 Cue（無関係・Cueなしを除外）について、第24層のX距離とスコアのSpearman相関 r_x、Y距離とスコアの相関 r_y、X/Y距離間の相関 r_xy を取得。順位は同順位平均。偏順位相関は (r_x-r_y*r_xy)/sqrt((1-r_y^2)*(1-r_xy^2))。Y側の偏相関も対称に計算した。Probeの元スコアから両単相関を再計算し、最大差2.22e-16で一致。Logit Lensは保存済み単相関を使用（大容量原CSVの取得制約により原スコアからの再計算は未実施）。全40行（10概念×2条件×2指標）。

## 解釈と限界

X/Y相対スコアとX距離の単相関はY距離との共変動を含む可能性がある。例：antのLensはX距離との相関 .672、Y距離との相関 .866、X/Y距離間 .749。Y調整後のX距離相関は .071。Probeでも正から負へ転じる。ただし、Y距離を調整しても絶対的X活性や因果効果は識別できない。X/Y距離の相関が高い概念（drum .821等）では推定が不安定になり得る。各概念20 Cue、未人手監査、事後分析であり、検定・CI・追加共変量の調整は未実施。低い相関の符号は特に慎重に扱う。本実験の刺激選定・統計計画の事前確定に向けた参考とし、既存データ・プロトコルは変更しない。
