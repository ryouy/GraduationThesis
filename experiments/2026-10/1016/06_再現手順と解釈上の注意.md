## 3. よくある誤解と正しい読み方

| 誤解 | 正しくは |
|---|---|
| 「禁止したら逆にXが出た＝白熊効果を再現」 | Mann型の関連1回ではNeutral 95%、Suppression 65%。**通常より増えたわけではない** |
| 「ReplacementはXを内部から削除した」 | 生成頻度やX/Yの相対Probeスコアが変わっただけ |
| 「否定は18.5%しか理解できない」 | 6語群の特定の三択・消去問題での尤度選択正答率。一般の否定理解を意味しない |
| 「Layer 24 AUC 0.972だから忘却しないと証明」 | 6例×8概念のProbe性能であり、時間的な残存・忘却の直接測定ではない |
| 「DIDが正だからSuppressしたXの活性がNeutral以上」 | Layer 24では**SuppressionのX/YスコアはNeutralより低い**。関連刺激に対する相対差が大きいという意味 |
| 「Logit Lensで抑制回路を発見」 | 測定したのは**選択肢ラベルの支持度**。因果介入なし |

## 4. 実験の検証単位と統計

- Mann：反復生成5回は1概念内の反復。**実質の概念単位は8つ**。
- Zhou：語順3回転・正解位置3回転を行っても**実質の語群単位は6つ**。
- Probe：各概念ペアごとに別の線形分類器を学習。**別の分類器のスコア尺度は必ずしも共通ではない**。
- Bootstrap区間は探索的な記述であり、標本数が少ないため一般化可能性は限定的。
- 同じ文型を使う少数の評価データは、他のトピックやモデルに外挿できない。
- 語彙が1トークンか複数トークンか、語頻度や文字列境界など、表層の要因も結果に影響する。

## 5. 最終層DIDの再集計（透明性のため）

`concept_probe_DID_v3.csv`のLayer 24について、平均と95%Bootstrap区間をこのフォルダ用に別途計算した。**この区間は元の `summary.json` には収録されていない追加の記述的解析**。

```python
import numpy as np
import pandas as pd

did = pd.read_csv("concept_probe_DID_v3.csv")
v = did.loc[did.layer == 24, "related_minus_unrelated_DID"].to_numpy()
rng = np.random.default_rng(42)
samples = rng.choice(v, size=(5000, len(v)), replace=True).mean(axis=1)

print("mean:", v.mean())                 # ≈ 0.518745
print("95% interval:", np.quantile(samples, [0.025, 0.975]))
# ≈ [0.307, 0.748]
```

このBootstrapは8概念を独立と仮定したもので、意味的・統計的な独立性を保証しない。また、Probeのスコアが概念ペア間で比較可能だという仮定にも依存する。

- Colab Secrets名：`GITHUB_RESULTS_TOKEN`（ノートブックアクセスをON）。
