## 2. 差し替えの判断基準

| 観点 | 採用基準 |
|---|---|
| Xへの関連 | 近・中・遠のすべてで、Xを連想する経路が文章内容から説明可能。単なる天候、一般的な商業活動、無関係な出来事は除外 |
| 自然さ | 英語の自然な1文として成立し、明らかな不自然・矛盾・曖昧な指示表現がない |
| 具体性 | Xが全く関与しない一般論より、交通施設、利用場面、関連道具・設備など具体的な手がかりを優先 |
| Yへの関連 | Yを直接指す文章を避け、XとY両方へのコサイン距離を必ず保存。間接的なY関連は排除せず記録 |
| 距離 | **近・中・遠の全区間で実測距離の重なりがない**こと、各帯4文を維持すること |
| 無関係Cue | Xへの連想経路がほぼない、別分野の1文として維持。関連Cueの「遠い」と混同しない |
| 研究独立性 | Qwen出力・抑制条件での反応を使って採否を決めない |

> 注意：弱い関連を維持しながら「遠い」距離を保つには限界がある。距離を最大化するより、解釈可能な関連性を優先した。そのため、元の暫定版と平均距離が少し異なる。選定した距離帯は**この候補集合内での相対区分**であり、0.3・0.6・0.9といった普遍的な閾値を意味しない。

## 5. 差し替え後も残る限界

1. **AI監査≠人手監査：** 採用理由は説明できるが、第三者が同じ評価をするかはまだ不明。人間の評価者が適合性を判定し、無理のある関連Cueは本パイロット前に別版として差し替える。
2. **距離と関連性は同じではない：** 「遠い」Cueであっても、暗黙の連想が可能な文章を選んだ。逆に、実際にモデルがXを想起することは保証されない。
3. **比較Yの影響：** 交通という共通領域により、バスとボート・ヘリコプターなどの概念が同時に連想されうる。 `distance_y` と `delta_x_minus_y` も残したので主分析時に確認する。
4. **文章の書き方の違い：** 近いCueは部品や構造、遠いCueは場面・施設になりやすい。距離以外の具体性・機能性の差は残る交絡であり、卒論では限界として報告する。
5. **4概念とも乗り物：** これは技術的なパイロット。異なる意味領域への一般化を主張しない。
6. **凍結の意味：** このファイルを再編集して元の選定経緯を消さない。人間の評価で修正が必要なら **v2を新規作成し、全ての差分と理由を記録**する。
