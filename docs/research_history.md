## 1. 研究がどう形になったか

研究は、「LLMは否定・抑制指示をどう処理するのか」「出力の裏にあるHidden Stateから、どのような情報が読み取れるのか」という広い関心から始まりました。初期には複数のテーマ候補を比較し、関連研究を参考にした小規模予備実験を行いました。その後、出力中の対象語の有無だけを見るのではなく、**抑制対象Xと手がかりCueの意味的距離が、生成直前の内部表現に読み出せるX/Y相対情報とどう関係するか**を中心の問いとして絞り込みました。

~~~mermaid
flowchart TD
    A["広い関心：否定・抑制とLLM内部表現"]
    B["候補比較：白熊効果、ベクトル表現、空間課題など"]
    C["先行研究を参考にした予備実験"]
    D["8概念・距離・層の探索とX/Y対照"]
    E["11月：測定妥当性とCue設計を検証"]
    F["現行案：Avoid X、100概念、連続距離分析"]
    A --> B --> C --> D --> E --> F
~~~

| 段階 | 中心的な問い | 具体例 |
|---|---|---|
| 現象を見つける | 「考えるな」と言われた概念は、出力や内部表現にどう現れるか | 「バナナを考えるな」と指示した後、果物に関する文章を読む |
| 測定方法を確かめる | Probeは概念情報を新しい文章でも読み取れるか | 概念名を含まない説明文からXとYを分類する |
| 距離を操作する | CueがXに近いか遠いかで内部スコアは変わるか | Xが「象」なら、長い鼻やサバンナに触れるCueと、離れた話題を比較する |
| 比較対象を統制する | 変化はXだけに関係するのか、Yにも近いのか | CueとXの距離dXだけでなく、CueとYの距離dYも測る |
| 本実験へ備える | 少数概念の発見を、より広い概念集合で再検証できるか | 10カテゴリーから最大100個のXを基準に沿って採択する |

## 2. テーマ候補の比較と絞り込み

プロジェクトに共有された候補資料では、「人間の心の不思議な現象」と「LLMの内部表現」を接続する複数の方向を比べました。ここに挙げる候補の多くは、テーマ検討の対象であり、実験を完了した研究テーマではありません。

| 候補 | 具体的に考えた課題 | 研究として測る案 | その後の位置づけ |
|---|---|---|---|
| 抑制・白熊効果 | 「ピンクのゾウを考えるな」と言うと、かえって対象が想起されるか | 禁止・置換・中立指示を比べ、出力と内部表現を調べる | 現在のテーマの出発点。単なる言及率比較から、距離と内部指標の関係へ発展 |
| LLM内部の意味表現 | 概念はどの層・方向・部分空間に表れるか | Hidden Stateから概念X/Yを分類し、層ごとに性能を測る | ProbeやLogit Lensを使う方法論の土台 |
| 絵文字・2D空間課題 | 絵文字や記号で表した迷路をLLMが解けるか | 正答率に加えて、位置・障害物・ゴールをProbeで読めるか調べる | 面白い比較案として検討。現在の卒論の主題には採用していない |
| 未知のオノマトペ | 架空の音の言葉から、感覚や印象を推測できるか | 人間評価、モデル評価、埋め込み空間を比べる | 独自性の候補。人手評価の設計が必要なため主題化せず |
| 夢のような物語 | 夢らしさや因果の飛躍をモデルが作る・認識するか | 因果飛躍、時空間の転換、人物同一性などを分解して評価 | 評価指標作りが大きく、卒論の期間内では設計負担が高い候補 |
| 自己対話による意味の変化 | 外部入力なしの反復対話で意味が漂流・収束するか | 各ターンの意味距離や内容変化を記録する | 哲学的な問いを数値化する必要があり、現主題には採用していない |

**絞り込みの判断：** 直感的に説明しやすい抑制現象を題材にしつつ、研究の中心は「モデルが本当に考えているか」という直接観察できない主張ではなく、**固定した条件のもとで、Hidden StateからX/Yの相対情報がどの程度読み出せるか**に置きました。

参考：[研究概要](research_overview.md) · [初期設計の記録](main_experiment_design_v0_5.md) · [旧プロトコル](main_experiment_protocol.md)

## 3. 時系列の詳細

### 2026年4月ごろ：否定表現と内部表現への関心

プロジェクト内の「否定表現理解の検証」では、既存ノートブックを一度に結論づけず、コードが何を測っているのかを段階ごとに確認しました。ここで重視したのは、LLMの最終回答だけでなく、内部表現も同時に見ることです。

**話し合った例：**

- 同じ対象について「考えて」「考えないで」と指示したとき、出力の違いは否定語の処理を表しているのか。
- Hidden Stateを各層から取得できても、どの層が何を「考えている」と直接読めるわけではない。まずProbeが何を分類しているかを明確にする。
- ノートブック末尾の自動総評に頼らず、条件、プロンプト、採点方法、実測結果を順に点検する。
- Cueや文章ベクトルの比較条件をきちんと構成し、内部指標と発話指標を合わせて解釈する。

**ここで形成された注意点：** ProbeはHidden Stateに含まれる情報を読み取る分類器であって、意識、注意量、忘却、抑制成功を直接測る装置ではありません。

関連資料：[分析手法と測定指標](methods.md) · [参考資料](reference/README.md)

### 2026年4月末〜夏：ベクトル空間と候補テーマの検討

「世界の共通言語」「人間の認知とベクトル空間」などの話題から、言語表現や概念がベクトルとしてどのように扱われるかを議論しました。続いて候補テーマを比較し、興味深さだけでなく、変数を定義できるか、比較条件を置けるか、卒論期間内に実施できるかを検討しました。

**具体例：**

- 「ピンクのゾウ」と「青い小鳥」のような架空・具体概念をX/Yとして、Xを抑制する指示とYへ置き換える指示を比べる案。
- 絵文字で迷路を表すなら、迷路の答えだけでなく、モデル内部から「現在位置」や「ゴール」を読み出せるかを見る案。
- 未知オノマトペなら、モデルの印象評定だけでなく、人間の評定と同じ軸で比較する案。
- 「夢らしい」や「孤独」といった抽象語は、そのままでは測りにくいため、観察可能な要素に分ける必要があるという整理。

これらの検討を経て、抑制指示と内部表現を中心に据える方針が強まりました。候補資料の全項目は、GitHubの正式プロトコルではなく、ChatGPTプロジェクトに共有されたテーマ候補メモに残っています。

### 2026年8月：卒論テーマと実行可能性の再確認

「卒論テーマ比較」では、候補テーマの独自性や実験の負荷を見直しました。研究上の問いを広げすぎず、使える計算資源で再現できる実験にすることが課題でした。

この時期以降の設計では、小型のオープンモデルを使い、ノートブックで条件・入力・出力・内部状態を記録する方針が中心になります。実行環境の不具合や計算時間は、テーマを諦める理由ではなく、対象モデルや実験規模を具体化する設計上の制約として扱いました。

### 2026年10月15〜16日：白熊効果・否定処理・Probeの予備実験

先行研究を参考に、Qwen2.5-0.5B-Instructを使った小規模な予備実験を実施しました。Mann型の抑制・置換実験、Zhou型の否定処理課題、Concept Probeの内部表現確認をまとめて調べています。原論文をそのまま再現した追試ではなく、卒論テーマを選ぶための予備検証です。

| 検証 | 実測 | 解釈上の注意 |
|---|---:|---|
| 関連Cue後の対象語出現 | Neutral 95.0%、Suppression 65.0%、Replacement 20.0% | 禁止で通常より出現が増えた厳密な白熊効果は確認していない。置換指示では言及が下がった |
| 無関連Cue後の対象語出現 | Suppression 2.5% | Cueが対象と関連するかで出力が変わる可能性 |
| Zhou型の肯定／否定課題 | 肯定100.0%、否定18.5% | 課題難度、選択肢、回答バイアスを分離できていない |
| 名前を直接含まない説明文のProbe | 平均ROC-AUC 0.972、8/8概念で0.75以上 | 概念情報が読み出せたことは、忘却や再活性化の直接証明ではない |
| 関連／無関連Cueの内部差 | 抑制条件特有の差の差が8/8概念で正 | 差の差が正でも、抑制条件の絶対スコアが通常より高いとは限らない |

この予備実験では、「出力に禁止語が出たか」だけでは研究の問いに十分答えられないことが明確になりました。次の段階では、関連／無関連の二択を、意味的距離の連続・段階的な違いに広げることになります。

### 2026年10月19日：距離・層別分析とX/Y対照へ

10月15日の実験から、手がかりの意味的距離を導入した実験へ進みました。最初のv1では8概念・64 Cue・6層を扱いましたが、距離順序が想定どおりだったのは8概念中4概念で、中間層のProbeも安定しませんでした。

そこでv2では、96 Cueに増やし、全24層を取り、同一入力系列のCue前後のHidden Stateを比較しました。学習に使わない説明文でProbeを評価し、Xを直接書く参照指示と抑制指示の対象語数を揃える工夫も行いました。

**この時点での設計例：**

- X＝象、Y＝キリン。
- Cue例の発想：Xに近い「長い鼻を持つ大型動物」、別の距離帯には生息環境や関連場面、無関係条件には直接の連想経路がない文章を置く。
- 「近・中・遠」というラベルだけを信用せず、MiniLMの埋め込みから実測距離を計算し、概念ごとに距離を並べ替える。
- Cue前後の差は同じ入力の別トークン位置の比較であって、時間が経つにつれ記憶が復活した様子を直接記録したものではない。

v2では最終層のProbeが8/8概念でAUC 0.75以上となり、想定した距離順も8概念中6概念で成立しました。一方、24層の結果を見てから効果の大きな層を選ぶ多重比較、概念数の少なさ、Cue文面の違いなどが残りました。そこでv3では、禁止対象Xと比較概念Yを入れ替え、Xに特異的な反応なのかを確かめる対照設計を作りました。

**重要な状態区分：** 10月19日のv3はノートブックと刺激を作成した段階で、当時のREADMEでは未実行と記録されています。コードを作ったことと結果を取得したことを混同しないでください。

### 2026年11月3〜4日：採点とモデル選択を点検

本実験へ進む前に、質問形式、モデルの回答性能、推論コード、採点器、Probeを点検しました。初回の自動採点では、否定文や句読点の扱いによって回答が誤分類される例が見つかりました。既存回答を再採点し、追加のモデル生成ではなく採点処理そのものを先に直したケースもあります。

**具体例：**

- 384件の保存済み回答を再採点し、15件の採点漏れを修正。
- Phiの回答では「none」に関する表記や文中のorによって、自動集計が内容と違う分類をするケースが見つかった。
- 4モデル比較では、Qwen系とPhi-3.5 miniを固定問題で比較。Phiが比較的高得点でも、事前に定めた条件をすべて満たすモデルはなく、採用を即断しなかった。
- 361入力からProbeスコアを得た診断では、対象名を指示文に含めただけでもスコアが変化し得ることが確認された。

この段階の教訓は、**モデルの高得点やProbeの高AUCを、そのまま研究対象の心理的・意味的効果と解釈しない**ことです。

### 2026年11月10〜12日：Probeの汎化・独立確認

20ペアから100概念へ対象候補を広げる途中で、Probeの評価例を学習例と分離しても、概念や説明文によって成績が変わる問題を詳しく調べました。

- 20組の分析では、既存の説明文と新規説明文で平均AUCが異なりました。概念ペアによって新規文章への汎化の良し悪しも大きく違いました。
- 最初の100概念試行では評価用説明文が少なく、再設計が必要と判明しました。
- 100概念v2では説明文を増やし、100候補中69概念を評価。探索的に12概念が複数距離帯で条件を満たしました。
- 23概念・184文の独立確認では、16対象中4対象がFDR感度分析後にも複数距離帯で再現しました。

これは本実験の抑制効果を測定した結果ではなく、**Probeを使う対象候補をどう選び、汎化をどう確かめるか**を調べた準備実験です。

### 2026年11月12日：パイロットCueの距離選定と内容監査

最初の本格的なCue距離パイロットでは、4つのXを乗り物から選び、各Xにつき60文、合計240候補を用意しました。

| X | 固定した比較概念Y | 選定したCue |
|---|---|---|
| boat | bus | 近4・中4・遠4・無関係4 |
| bus | helicopter | 近4・中4・遠4・無関係4 |
| bicycle | submarine | 近4・中4・遠4・無関係4 |
| motorcycle | helicopter | 近4・中4・遠4・無関係4 |

64文を距離に沿って選び、AIによる内容監査の結果17文を、未選定だった同じ240候補の中から差し替えました。たとえば、bicycleの遠距離Cueで「街の散策」のような一般場面を、空気入れや反射ジャケットが登場する間接関連の場面に変えています。boatでは一般的な旅行計画を運河ツアーの場面へ、busでは一般的な時刻表をターミナルや待合シェルターに関する場面へ寄せる判断がありました。

監査後、各概念で近・中・遠の実測距離範囲は重なりませんでした。ただし、これはAIによる質的監査で、人間の独立評定ではありません。また4概念すべてが乗り物なので、別カテゴリーへの一般化を示す結果ではありません。

資料：[距離選定結果](../experiments/2026-11/1112_cue_semantic_distance/results/20261112_cue_distance_pilot_v1/analysis_summary.md) · [固定64文と変更理由](../experiments/2026-11/1112_cue_semantic_distance/final_stimuli/20261112_frozen_ai_audit_v1/README.md)

### 2026年11月12〜13日：4条件の抑制パイロット

固定したCueセットを使い、Qwen2.5-0.5B-Instructで4概念のパイロットを実施しました。4条件はBase、Think X、Avoid X、Think Yです。各Cue条件で5回生成し、出力だけでなく、生成直前Hidden State、Probe、全24層のLogit Lensを保存しました。

**具体的な対象例：**

- boat → bus
- bus → helicopter
- bicycle → submarine
- motorcycle → helicopter

パイロットでは、明示的なXの文字列が出たか、回答が意味的にXそのものを指しているかを別指標にしました。Avoid Xでは、関連Cueの近・中・遠群に対する厳格な意味的X同定率が51.3%、12.5%、5.0%でした。これは4概念・特定Cue集合における探索的な観察で、因果効果や全概念への一般化を確定するものではありません。意味判定はAPIによるもので、人手正解ラベルではありません。

資料：[パイロットの統合解釈](../experiments/2026-11/1112_qwen_suppression_pilot/results/20261112_qwen_suppression_pilot_v1/INTERPRETATION_20261113.md) · [全実験の索引](experiment_index.md)

### 2026年11月24日：Neutral X条件を追加

4条件の比較では、BaseとAvoid Xで対象名の提示有無が違うため、「抑制指示」と「プロンプトに対象語を書いた効果」が混ざる可能性がありました。そこで対象名を提示しながら抑制しないNeutral X条件を追加し、68入力・340回答で固定ProbeとLogit Lensも取得しました。

関連Cueに対する明示的なX言及率はNeutral X 57.9%、Avoid X 34.6%でした。この比較は、禁止指示だけの純粋な因果効果を示すものではありません。むしろ、**対照条件を工夫しないとプロンプトの語そのものが測定値に影響する**ことを示す設計上の注意になりました。

資料：[Neutral X追加検証](../experiments/2026-11/1112_qwen_suppression_pilot/results/20261124_qwen_neutral_x_addon_v1/analysis_summary.md) · [条件選定の判断メモ](neutral_x_control_decision_v0_1.md)

1. **Probe候補の広げ方：** 50組の均衡版v5では33組が旧基準で暫定通過。ただし、正式な100概念採択や人手監査はまだです。

3. **Yカテゴリー：** 同じカテゴリーに限定することを必須にせず、dXYが0.6以上の候補を優先する方針。ただし0.6は探索的な優先目安で、普遍的な閾値でも必須条件でもありません。

5. **XとY双方への距離：** dXだけでなくdYも算出し、Cue選定後にdXとdYの相関や帯ごとのdY差を診断。Cue数を最大限保ちながら、両方を考慮するjoint選定を検討しました。
6. **制約の比較：** v6では距離幅±0.06と±0.08を含む条件を比べ、統合実験Eでは同一候補集合で旧・改良条件を比較しました。v0.98では中心から最大±0.06、隣接帯間の最小空白0.01を採用。距離帯は候補集合内の相対区分として扱い、連続距離dXを主解析に使います。
7. **成功と品質の区別：** 24文をそろえ、距離診断を満たすことは数値・構造上の成功です。文章が自然でXに適切に関連することや、人間が同意することを自動的に保証しません。

## 4. 方法を具体例で整理

### 4.1 指示条件の例

| 条件 | 指示例 | 役割 |
|---|---|---|
| Avoid X | Do not think about {X}. Read the clue and briefly name the thing it brings to mind. | 抑制指示下で距離と内部スコアの関係を見る主条件 |
| Neutral X | The word is {X}. Read the clue and briefly name the thing it brings to mind. | Xの名称は示すが抑制しない比較条件 |
| Cueなし | No clue is provided. Answer with one short phrase. | 手がかりがない場合の基準 |

旧パイロットにはBase・Think X・Avoid X・Think Yの4条件もありました。これらは研究の設計がどう進んだかを理解するための履歴であり、v0.98の本実験条件はAvoid XとNeutral Xを中心にしています。

### 4.2 Cue距離の例

Xがbicycleなら、文章の具体的内容がXとの連想経路を持つかを監査したうえで、固定埋め込みからdXを計算します。距離帯の例を説明するために「自転車のタイヤ」「駐輪ラック」「反射ジャケット」のような語を挙げられますが、語がそのまま本実験の凍結Cueであるとは限りません。実際の刺激は候補ID・文面・距離・採否理由をCSVで追跡します。

パイロットの監査では、「遠い」CueでもXへの説明可能な連想経路を残しました。たとえば単なる街歩きの描写を、空気入れや反射ジャケットが出る移動場面へ置き換えています。これは意味的距離と関連性を別々に点検する例です。

### 4.3 ProbeとLogit Lensの違い

| 方法 | 入力と出力の例 | 読めること／読めないこと |
|---|---|---|
| Concept Probe | X＝象、Y＝キリン。Hidden Stateを入力し、「象側／キリン側」の相対情報を出す | Probeの学習・独立評価文で識別可能な情報。対象概念の絶対活性や意識を直接測るものではない |
| Logit Lens | 各層の状態からX候補語・Y候補語の対数尤度を求め、平均対数尤度差を計算する | その層で候補語の系列がどれだけ予測されるか。モデルの全思考過程そのものではない |
| 最終出力の評価 | 回答に「象」と明記されたか、別表現でも象を指すか、Cue自体が妥当かを個別採点 | 発話上の反応。内部スコアと同じものではなく、採点規則・評価者の妥当性確認が必要 |

## 5. 研究判断の変化とその理由

| 以前の案・発見 | 問題として分かったこと | 現行設計での対応 |
|---|---|---|
| 関連／無関連Cueだけで比べる | 距離の違いを細かく扱えず、文章内容の差も大きい | 関連Cueを5距離帯にし、主解析では実測dXを連続値として使う |
| 高い学習内AUCでProbeを採用する | 新しい説明文では成績が低下する概念があった | 64/32/32に分け、独立最終確認と補正済み基準を設ける |
| Xとの距離だけを見る | X/Yの相対判別ではCueがYにも近い可能性がある | dYも保存し、Cue選定と解析の双方で考慮 |
| 手作業の近・中・遠ラベルを信じる | 実測距離では順序が崩れる概念があった | 固定埋め込みで計測し、候補内の五分位と実測値を保存 |
| 自動採点を正解扱いする | 表記ゆれ・否定・句読点で誤判定する | 言及、意味的同定、Cue妥当性、形式遵守を分け、人手確認を未完了課題として記録 |
| AvoidとBaseだけで比較する | 対象語をプロンプトに含むかが異なる | Xを両条件に含めるNeutral Xを補助対照に採用 |
| 距離帯の閾値を固定値とみなす | 埋め込み値は候補群やモデルに依存しうる | 相対帯に加え、連続距離dXを主解析にする |
| ProbeとLogit Lensを一つの指標にまとめる | 読み出し機構が異なり、結果が一致しない場合もある | 二つの内部指標を別々に報告し、不一致も結果として扱う |
