# ⑤ 本実験デザイン・解析仕様案 v0.5

> 2026-11-24。**設計案であり、確定プロトコルv1.0ではない。本実験は未実行。** パイロットの結果を踏まえて作成したため、予備的知見と将来の本実験分析を明示的に区別する。既存パイロットの刺激・データは変更しない。

## 1. 研究目的

LLMにおける「Xについて考えないで」という抑制指示と手がかりCueの意味的距離により、生成開始直前の内部表現・固定語彙への投影がどう変わるかを調べる。最終生成は内部解析との対応を検討するための補助指標とする。

- **RQ1**: 抑制指示は同一X/YペアのHidden Stateから得られる線形Probe判別スコアをどう変化させるか。
- **RQ2**: Probe・Logit Lensの条件差はCueの意味的距離・Transformer層によりどう異なるか。
- **RQ3**: 二つの内部指標の一致・乖離と、最終出力のX明示言及との関係はどうか。

**測定の限界**: ProbeはX/Y相対判別値、Logit Lensは固定文字列の語彙投影の評価であり、概念の絶対的な活性量・「思考量」を測定したことにはならない。距離もCue文章の具体性と共変する。

## 2. 本実験の規模（推奨）

- **目標X＝20概念、5領域×4概念**：交通手段、動物、楽器、食べ物、日用品などを候補とする。これは**提案のカテゴリー**であり、各概念とYはまだ採択・固定していない。
- **Xにつき16 Cue**：near/medium/far各4、unrelated4。さらにXにつきCueなし1。
- **5指示条件**：Base / Think X / Avoid X / Think Y / Neutral X。中立条件は `The word is {X}. Read the clue and briefly name the thing it brings to mind.`。他の4条件と後続Cue・回答形式は既存パイロットの固定文面を使用。詳細は[元パイロットのノートブック](../experiments/2026-11/1112_qwen_suppression_pilot/qwen_suppression_pilot_4concepts.ipynb)。
- **ユニーク入力：20×(16+1)×5＝1,700**。**生成：1,700×5 seed＝8,500回答**。Probe第22/23/24層なら理論上5,100スコア、Logit Lens 1–24層×X/Y候補なら81,600行。各入力の生成前Hidden Stateは反復5回で重複計上しない。
- モデル：`Qwen/Qwen2.5-0.5B-Instruct`、revision `7ae557604adf67be50417f59c2c2f167def9a775`。埋め込み：`sentence-transformers/all-mpnet-base-v2`、revision `e8c3b32edf5434bc2275fc9bab85f82640a19130`。生成はseed `[101,211,307,401,503]`、temperature=0.7、top_p=0.9、max_new_tokens=128。ランタイム・依存版をmanifestへ記録。
- GPU資源・実行時間は実際に計測していないため、上記規模が一回のColabで実行可能と保証しない。**中断再開型チェックポイントを用い、モデル条件を変えずに複数セッションへ分割**する。

## 3. 概念X・比較Y・Cueの採択（本実験の生成結果を見ない）

1. 概念候補を複数領域から選出し、XとYの関係・概念重複・語の曖昧さを点検。XとYの対応は各Xに1つ事前固定する。20個すべてが既に独立Probe検証済みという意味ではない。
2. **Probeを主解析に含めるには**：X/Yの独立した未学習説明文でROC-AUCとラベル置換・多重比較感度を評価し、基準・データ・採否を本実験の条件結果を見る前に固定する。暫定下限はheld-out AUC≥0.80、未学習文の各ラベル≥8、FDR補正下のシャッフル検査q<0.05。これは**提案閾値**。正式v1.0では概念選抜の実行前に適用基準・シャッフル反復数・FDR対象の比較集合を凍結する。通らない組を結果で救済せず、出力/Logit Lensの対象からも自動削除しない。必要に応じてX候補をあらかじめ多めに準備し、20組採用を目指す。
3. 20組に達しない場合、追加検証を無期限に続けない。**採択済み組数を正直に報告し、Probe分析対象数を減らす**。20という目標に合わせて恣意的に評価基準を緩めない。
4. 各Xについて、後続条件結果を見ずにCue候補を作り、語の露出・不自然さ・重複を点検。固定定義文とcueのコサイン距離を測り、関連Cueから距離の近・中・遠各4、無関係4を選ぶ。**近中遠は文ごとの実測連続距離も必ず保存**する。名称・固定同義語がCueに出ないか自動検査する。
5. 生成結果を見てからCueを差し替えない。新旧の刺激ファイル・選定コード・SHA256・各X/Yの比較を記録。Cueの内容が距離と共変する点を限界として扱う。

## 4. 主解析の操作的定義

**主条件比較**：同一X・Y・Cueで `Avoid X − Neutral X`。副次 `Avoid X − Think X`。BaseはX名称が提示されないため主たる抑制効果の比較としない。

**主解析① Probe**：
- 第24層の固定ProbeのX側decision functionについて、同じX/Yペア内のCue対応差 `D_probe(X,Cue) = Score(Avoid X)−Score(Neutral X)`。
- 第22/23層は層別感度分析。異なるX/Yペアの生スコアは直接平均しない。必要な標準化の方式は本実験結果を見る前に、学習・検証セット由来の尺度で決める。
- 未学習説明文での高AUCを「抑制の測定妥当性が保証された」とは書かない。

**主解析② Logit Lens**：
- 予め固定したXとY候補文字列のteacher-forced sequence log probabilityを全24層で測り、同一X/Y・Cue・層で `Margin=logP(X)-logP(Y)` と `D_lens=Margin(Avoid X)-Margin(Neutral X)` を算出。
- **第24層を主たる要約層**とし、1–24層の軌跡を層別分析として示す。単一トークンLogit Lensと複数トークンのteacher-forcing系列評価は混同しない。tokenizer分割・候補文字列長を保存。
- 出力logitsとの一致（最終層）を実装監査し、閾値と再現許容範囲を実行前にコードで固定する。

**補助：最終出力**：事前辞書によるExplicit Mention Rate。Semantic Mention Rateは参考的なstrict identification評価。辞書・API・人手監査の結果を混同しない。API採点が実施できなくても内部主解析は成立する。

## 5. 統計・可視化・多重比較

- **独立性を保つ単位**：Cue（概念X内の反復Stimulus）、その上位のX概念。5回の生成は出力確率の推定であり、5件を独立した内部状態として扱わない。
- **距離の扱い**：本解析は実測連続コサイン距離。概念ごとに距離の平均を中心化して、Cue対応差と距離の関連をみる。near/medium/farは図示・層別感度分析。unrelatedとCueなしは距離回帰の対象外。
- **要約と不確実性**：各X内でCue単位の効果と距離傾向を計算し、概念ごとの効果分布を表示。概念間の一般化は慎重にし、概念単位の層化（カテゴリーを維持した）ブートストラップなどを利用して不確実性を表示する。小カテゴリー数や非無作為概念選抜の限界を付す。
- **Probeの異ペア比較**：生のdecision値は比較できない。一次要約はXごとの変化方向・Cue内の傾向とし、横断効果量を出す場合は本実験結果に依存しないスケーリングを先に固定する。
- **Logit Lensの層別分析**：全24層の逐一有意差を主張しない。可視化を主とし、検定するなら事前に定めた層/比較集合にFDR補正を適用する。
- **複数の主指標**：ProbeとLogit Lensは別の測定量であり、方向が違っても両方報告する。統計的有意性の主張には二つの主解析・複数比較に伴う多重性を考慮し、効果量と不確実性を中心に結論づける。
- 結果は「距離属性と内部指標の関連」として解釈し、「距離だけを操作した因果的抑制」とは主張しない。

## 6. 実験品質・除外・停止

- 生成前に同一モデルrevision/chat template、Cue集合、Probe学習器、候補X/Y文字列、乱数、コード・依存版、除外条件をmanifestとGit SHAで凍結。
- プロンプト欠損、重複ID、非有限内部値、異なるモデルrevision、保存チェックポイント不整合は**品質エラー**として修正し、同一条件で再実行。得られた効果の方向で除外・再選択しない。
- 形式逸脱・空回答・無意味出力は**観測値として保存し報告**。内部スコアの品質に直接影響しない限り、勝手に捨てない。
- 1回の完結した本実験を優先。低い効果量や期待と逆の結果を理由に実験条件やCueを作り直さない。
- 出力評価①の人手監査およびCue③の独立人手監査は未完了。主結果が内部指標であっても、未実施の監査を「済」と書かない。指導教員と必要な範囲を判断。
