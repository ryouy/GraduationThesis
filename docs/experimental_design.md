# 実験設計と分析計画

[← リポジトリのトップへ戻る](../README.md) · [研究概要](research_overview.md)

## 1. 基本となる実験条件

現時点では、以下の4条件を基本設計とする。

| 条件 | 役割 |
|---|---|
| Base | 指示なしの基準条件 |
| Think X | 対象概念Xへ注意を向ける条件 |
| Avoid X | 対象概念Xを抑制する条件 |
| Think Y | 比較対象Yへ注意を向ける条件 |

各条件のプロンプトは、対象名の提示や文面の違いが結果に与える影響を考慮して設計する。

## 2. 主な比較

| 比較 | 主に確認すること |
|---|---|
| Avoid X − Base | 対象名の提示を含めた、抑制指示全体の影響 |
| Avoid X − Think X | 両方でXを提示したうえで、禁止と集中の違い |
| Think Yと他条件 | 代替概念への誘導との違い |

いずれか一つの比較だけで「純粋な抑制効果」と断定しない。主比較・主指標・分析対象の層などは、本実験の結果を見る前に固定する。

## 3. 概念とCueの設計（2026年11月12日更新）

本ページは研究方針の概要であり、現行の具体的な実行仕様は[本実験プロトコル](main_experiment_protocol.md)を優先する。

**次回パイロットは4概念：boat / bus / bicycle / motorcycle。** 比較Yはそれぞれbus / helicopter / submarine / helicopter。選定理由は、[独立した未使用説明文によるQwen Probe再評価](../1112_qwen_probe_independent_confirmation/results/20261112_newfacts_16targets_v1/analysis_summary.md)で相対的な識別性能が比較的再現したため。**この4概念に絞った結果を、他の意味領域へ一般化しない。**

[all-mpnet-base-v2による実測](../1112_cue_semantic_distance/results/20261112_cue_distance_pilot_v1/analysis_summary.md)では、4概念×60文＝240候補から64文を暫定選定。その後、[64文のAI内容監査](../1112_cue_semantic_distance/final_stimuli/20261112_frozen_ai_audit_v1/README.md)で17文を差し替え、各概念の近・中・遠各4文と無関係4文を維持した。**人間による独立評価は未実施**。

パイロット規模案：**4概念 × 16 Cue × 4指示条件＝256入力**、さらに **4概念 × 4条件＝16入力** のCueなし対照を追加して、合計**272ユニーク入力**。各5回生成するなら**1,360応答**となる。ただし、同じCueの生成反復は独立したCueとはみなさず、生成前Hidden Stateも反復ごとの独立サンプルとしては数えない。

Cueの距離は連続値を主分析で使用し、近・中・遠を説明用の層別表示として併用する。無関係Cueは関連Cueと分離して扱う。距離だけでなく文長・具体性・自然さ、比較Yへの距離、明示的な名称の混入を監査する。

## 4. 推奨する実験・分析の順序

### Step 1：測定方法の信頼性確認

- 意味的距離の算出方法とCueの妥当性を確認する。
- Probeの識別性能と汎化性能を検証する。
- 学習データと評価データを適切に分離する。
- 特定のCueや評価文への依存がないか確認する。
- モデル・課題・採用基準を事前に定める。

### Step 2：Probeによる主要分析

- 各層のHidden Stateを抽出する。
- Base、Think X、Avoid X、Think Yを比較する。
- 近いCueと遠いCueの違いを調べる。
- 条件・距離・層の関係を定量的に分析する。

### Step 3：最終出力との対応分析

- 各条件におけるXの出現率を比較する。
- 内部表現の識別可能性と出力結果の関係を調べる。
- 内部表現と出力が一致する場合・乖離する場合を整理する。

### Step 4：Logit Lensによる追加分析

- 各層におけるX関連トークンの予測確率を追跡する。
- 抑制指示やCueの距離による予測推移の違いを調べる。
- Probeや最終出力の結果と照らし合わせる。

## 5. 分析上の注意

- 距離の効果と、Cue自体の文面・具体性・頻出度の影響を区別する。
- Xへの関連性だけでなく、Yへの関連性も確認する。
- Probeの学習・評価データの漏洩を避ける。
- AUCを概念の活性量として解釈しない。
- Logit Lensの予測を実際の生成過程そのものとみなさない。
- 探索的に見つけた傾向と、事前に定めた主分析を区別する。
- 予想と異なる結果や、明確な効果が見られない結果も記録する。

## 6. 予備実験後の判断

| 到達した状態 | 進め方 |
|---|---|
| 課題もProbeも安定 | 回答と内部表現を本実験の中心にする |
| 課題は安定、Probeは不安定 | 回答を主結果、内部表現を探索的結果にする |
| 課題自体が不安定 | モデル・課題を再選定してから本実験へ進む |

内部表現の測定が完全に整うまで研究全体を止めない。予備実験で各指標の信頼性を確認し、どの指標を主結果として扱えるかを判断する。
