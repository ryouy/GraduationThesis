# 実験設計と分析計画

[← リポジトリのトップへ戻る](../README.md) · [研究概要](research_overview.md)

## 1. 基本となる実験条件

現時点では、以下の4条件を基本設計とする。

| 条件 | 役割 |
|---|---|
| Base | 指示なしの基準条件 |
| Think X | 対象概念Xへ注意を向ける条件 |
| Avoid X | 対象概念Xを抑制する条件 |
| Think Y | 比較対象Yへ注意を向ける条件 |

各条件のプロンプトは、対象名の提示や文面の違いが結果に与える影響を考慮して設計する。

## 2. 主な比較

| 比較 | 主に確認すること |
|---|---|
| Avoid X − Base | 対象名の提示を含めた、抑制指示全体の影響 |
| Avoid X − Think X | 両方でXを提示したうえで、禁止と集中の違い |
| Think Yと他条件 | 代替概念への誘導との違い |

いずれか一つの比較だけで「純粋な抑制効果」と断定しない。主比較・主指標・分析対象の層などは、本実験の結果を見る前に固定する。

## 3. 概念とCueの設計

これまでの研究では8概念を扱ってきた。今後の本実験でも8概念を基本候補とするが、モデル・課題・刺激の予備検証後に最終決定する。

実験規模の案：

**8概念 × 12手がかり × 4条件 = 384入力**

これは設計案であり、確定済み・実行済みの本実験データ数ではない。

手がかりは意味的距離を連続値として記録し、近い・中程度・遠いという区分は可視化や説明に使う。Cueの数だけでなく、独立した手がかりの種類を確保する。反復生成を行う場合も、同じCueの反復を独立した刺激とは数えない。

## 4. 推奨する実験・分析の順序

### Step 1：測定方法の信頼性確認

- 意味的距離の算出方法とCueの妥当性を確認する。
- Probeの識別性能と汎化性能を検証する。
- 学習データと評価データを適切に分離する。
- 特定のCueや評価文への依存がないか確認する。
- モデル・課題・採用基準を事前に定める。

### Step 2：Probeによる主要分析

- 各層のHidden Stateを抽出する。
- Base、Think X、Avoid X、Think Yを比較する。
- 近いCueと遠いCueの違いを調べる。
- 条件・距離・層の関係を定量的に分析する。

### Step 3：最終出力との対応分析

- 各条件におけるXの出現率を比較する。
- 内部表現の識別可能性と出力結果の関係を調べる。
- 内部表現と出力が一致する場合・乖離する場合を整理する。

### Step 4：Logit Lensによる追加分析

- 各層におけるX関連トークンの予測確率を追跡する。
- 抑制指示やCueの距離による予測推移の違いを調べる。
- Probeや最終出力の結果と照らし合わせる。

## 5. 分析上の注意

- 距離の効果と、Cue自体の文面・具体性・頻出度の影響を区別する。
- Xへの関連性だけでなく、Yへの関連性も確認する。
- Probeの学習・評価データの漏洩を避ける。
- AUCを概念の活性量として解釈しない。
- Logit Lensの予測を実際の生成過程そのものとみなさない。
- 探索的に見つけた傾向と、事前に定めた主分析を区別する。
- 予想と異なる結果や、明確な効果が見られない結果も記録する。

## 6. 予備実験後の判断

| 到達した状態 | 進め方 |
|---|---|
| 課題もProbeも安定 | 回答と内部表現を本実験の中心にする |
| 課題は安定、Probeは不安定 | 回答を主結果、内部表現を探索的結果にする |
| 課題自体が不安定 | モデル・課題を再選定してから本実験へ進む |

内部表現の測定が完全に整うまで研究全体を止めない。予備実験で各指標の信頼性を確認し、どの指標を主結果として扱えるかを判断する。
