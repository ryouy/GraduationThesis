# 本実験：内部表現の測定方法（2026-11-26）

[統合プロトコルv0.95](main_experiment_protocol_v0_95.md)第6–9節に対する更新メモ。2026-11-26の合意に基づく採用方針。実装・検証は未実施、v1.0は未凍結。

## 測定位置・層

- 生成開始直前の最後の入力トークンのHidden Stateを、各ユニーク入力につき1回、全24層について取得する。
- 第24層を主解析とし、第22・23層を既定の感度分析、第1–21層を探索的な層別分析とする。
- Concept ProbeとLogit Lensを併用する。生成反復は内部測定の独立サンプル数を増やさない。
- 複数トークンの候補系列評価で必要となる候補接頭辞位置の測定は、上記の生成直前の測定と区別する。

## 1. Concept Probe

概念ペア×層ごとに独立に学習した固定Linear Probeを使用し、Xを正例とする符号を固定する。

| 指標 | 用途 |
|---|---|
| Decision Function（生スコア） | 主測定指標 |
| 標準化Decision Function | 概念間・層間の比較、回帰分析、条件間比較 |
| Probability | 参考値として保存 |
| ROC-AUC | 独立評価文に対するProbeの識別性能 |

Decision Functionを主指標とすることで、Probabilityの0・1付近での飽和によるスコア変化の圧縮を避ける。いずれも概念を思考している量そのものではない。説明文での高いAUCは、本実験の異なる入力形式での測定妥当性を保証しない。

### 標準化

学習に使用していない独立評価用のX/Y説明文（各同数）をまとめた基準集合に固定Probeを適用する。概念ペア×層ごとにDecision Functionの平均μと標準偏差σを求め、固定する。

`z = (s - μ) / σ`

同じ基準パラメータをAvoid X・Neutral X・全Cue・Cueなしに共通適用する。本実験の条件別スコアから正規化パラメータを再推定しない。生スコア、標準化スコア、基準集合のID、μ・σを保存する。

標準化は分類器間のスコア尺度の違いを軽減するが、測定の等価性を保証しない。z=0は基準集合の平均であって、分類境界や概念情報の不存在を意味しない。学習時の特徴量StandardScalerとは区別する。

標準偏差の算出規約・極小または非有限のσの判定と処理、基準集合の独立性および安定性の確認方法は、Probe検証結果を踏まえてv1.0で固定する。不安定な標準化値を無条件に使用しない。

## 2. Logit Lens

各層のHidden Stateに必要な最終正規化とlm_headを適用し、固定候補表記のトークンごとの対数確率を取得する。複数トークンの場合はteacher forcingで候補の接頭辞を入力し、後続トークンを同じ層の出力投影で評価する。

層lにおける候補Wの長さをn_W、元の入力をc、候補のi番目のトークンをw_iとし、以下を定義する。

- 合計対数尤度：`L_l(W) = Σ_i log p_l(w_i | c, w_<i)`
- 平均対数尤度：`S_l(W) = L_l(W) / n_W`
- 主指標（平均対数尤度マージン）：`M_l = S_l(X) - S_l(Y)`

正のマージンはXのトークン当たり平均対数スコアが相対的に高いことを示す。トークン数による合計スコアの影響を軽減するが、候補系列全体の発生確率や概念自体の確率を示すものではない。中間層の投影スコアは通常の最終層生成確率と区別する。複数トークンのteacher-forced系列評価は単一位置の通常のLogit Lensとは異なる測定として明記する。

| 測定値 | 用途 |
|---|---|
| 平均対数尤度マージン | 主指標 |
| 合計対数尤度マージン | 感度分析（旧プロトコルの指標も保存） |
| 最初のトークンの対数確率 | 参考指標 |
| 各候補・各トークン・各層の対数確率 | 生データ |

候補表記・トークン境界・先頭スペース・トークンID列・長さを固定・保存する。X/Yのトークン数を同程度にする選定方針は維持する。最終層の各トークンの値についてnative forward logitsとの一致を確認し、数値許容誤差・正規化の適用位置をv1.0で確定する。

## 3. 概念間・層間の比較

- 生のProbe Decision Functionの絶対値を異なる分類器間で直接一括平均しない。
- 意味的距離とスコアの関係を主題とし、概念内のSpearman相関係数および標準化スコアを用いた回帰傾きを比較に用いる方針。主統計推定器・共変量・信頼区間・多重性等は別途確定する。
- 標準化された値や相関係数による比較も、測定器の信頼性や刺激分布の違いを考慮して解釈する。
- Avoid Xを主対象、Neutral Xを副次対照とする既存方針を維持する。

## 4. 低識別性能層

- 全24層のProbeスコア、AUC、検定結果、通過フラグを保存する。
- 概念のProbe採択は第24層の基準で行う。中間層の低性能だけで概念全体を除外しない。
- 低識別性能層は図示時に明示し、信頼できる概念指標としての解釈を制限する。低AUCは概念情報の不存在を意味しない。
- 層間比較では共通の通過概念集合による感度分析も行い、層ごとの有効概念数を記録する。
- 正式なAUC・検定・多重比較の採択条件は進行中のProbe検証結果を踏まえて確定する。
