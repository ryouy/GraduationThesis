> 2026年11月11日更新。最新のProbe再解析結果は[11月11日の結果整理](../1110_probe_reanalysis/FINDINGS_20261111.md)を参照。以前の実験については各リンク先の実行時点の記録を保持する。

## 1. 現在の結論

**本実験に使用するモデル・質問形式・内部測定方法は、まだ確定していない。**

モデル比較、質問形式、採点処理、Probeの診断を進めたが、現時点では基本課題の安定性とProbeの測定妥当性に追加確認が必要である。Phi-3.5 miniは次の確認候補だが、本実験への採用は保留している。

### 2.5 指示×手がかりProbe診断（11月4日）

361入力から24Probe・2,280スコアを取得し、保存特徴・係数からの再計算と一致した。

- 事前の主測定で象／キリンのみ校正フラグOK（AUC 1.000、シャッフル95%点0.918）。
- 手がかりなしでも象名提示でスコアが-0.539から0.875へ変化。
- 象／キリン説明の識別AUCは全5指示で1.000。
- 指示由来の反応と説明情報の両方が含まれる可能性があり、絶対スコアを思考量として解釈しない。
- 残る2組はシャッフル対照でも満点が多く、校正未達。

詳細：[指示×手がかりProbe診断](../1104_instruction_probe/results/instruction-probe-20261104T024551489146Z/REVIEW.md)

### 2.6 20組のProbe診断と再解析（11月4日・11月11日）

Phi-3.5-mini-instructの20組・40概念について、11月4日の保存済みHidden Stateを使用してProbe校正を再確認し、11月11日に新規評価文で汎化を検証した。

| 指標 | 結果 |
|---|---:|
| 既存の説明文での平均AUC | **0.9996** |
| 新しい説明文での平均AUC | **0.8436** |
| ランダムラベルでのAUC = 1.0 | **1,742/25,200（6.91%）** |
| 学習ラベル置換の未補正 p < 0.05 | **25/100構成** |

概念ペアごとに性能差が大きく（象／キリンの新評価AUC平均0.536、ピアノ／バイオリン0.880、イルカ／サメ0.992）、**従来の高AUCのみでは汎化性能・測定妥当性を保証できない**。5構成は学習データを共有する感度分析であり、独立反復ではない。新規刺激はAI作成のため人手での品質点検が必要。

**結論：** Probeが一律に機能しないわけではないが、そのスコアを「概念を考えている量」と同一視しない。Probeを本実験へ採用する前に、刺激の一意性・汎化性能・ラベル置換対照を確認する。抑制指示の因果効果は、この検証では測定していない。

詳細：[11月11日の結果・解釈・元データへのリンク](../1110_probe_reanalysis/FINDINGS_20261111.md) · [実験README](../1110_probe_reanalysis/README.md) · [元の20組Probe診断](../1104_instruction_probe_20pairs/README.md)

## 3. これまでの予備実験から分かった課題

| 課題 | 観察されたこと | 次に行うこと |
|---|---|---|
| 質問形式の安定性 | 近い手がかり9件で自由回答の対象名言及は3/9。二択は順序により5/9・7/9。全36件では順序変更で16件の回答分類が変化 | 質問形式と回答分類を事前に固定して再確認 |
| Probeの汎化 | 11月11日の独立説明文検証では平均AUCが0.9996→0.8436。概念ペア別に大きなばらつき | [新規説明文を人手で点検し、採用基準を定義](../1110_probe_reanalysis/FINDINGS_20261111.md) |
| X/Yへの関連性 | 各12手がかりでX/Y類似度のSpearman相関は0.783〜0.944 | Cue設計とX/Y双方への関連性を点検 |

これらは少数の手製刺激による診断結果であり、全般的な性能の確証ではない。X/Y類似度の強い相関も、それだけで実験失敗を意味しないが、相対スコアの解釈に注意が必要である。

## 4. 次に進めること

優先順位は以下のとおり。

1. **[20組Probe再解析の結果を踏まえて測定方法を見直す](../1110_probe_reanalysis/FINDINGS_20261111.md)。** 新評価文の一意性・事実性、概念ペア別の汎化性能、シャッフル対照を点検し、採用基準を定める。
2. **質問形式と採点規則を固定する。** none対照、同義表現、複合語、否定表現などの判定を事前に定義する。
3. **Cueを見直す。** Xへの意味的距離に加え、Yへの関連性、文章の長さ、具体性、自然さを確認する。
4. **モデル・課題・測定方法の採用基準を固定する。** 抑制効果の大きさを理由にモデルを選ばない。
5. **本実験の設計を固定して実行する。** 実行後に都合よく条件や評価規則を変えない。

## 5. 本実験へ進む判断基準

| 状態 | 方針 |
|---|---|
| 課題もProbeも安定 | 回答と内部表現を本実験の中心にする |
| 課題は安定、Probeは不安定 | 回答を主結果、内部表現を探索的結果にする |
| 課題自体が不安定 | モデル・課題を再選定してから本実験へ進む |
