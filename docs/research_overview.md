# 研究概要

[← リポジトリのトップへ戻る](../README.md)

## 1. 研究テーマ

**抑制指示下における手がかりの意味的距離がLLMの内部表現と出力に与える影響**

「Xについて考えないで」という抑制指示をLLMに与えたとき、対象概念Xに関連する手がかり（Cue）の意味的距離によって、モデルの内部表現と最終出力がどのように変化するのかを分析する。

## 2. 背景と問題意識

人間の心理学では、あることを考えないようにする行為が、かえってその対象への注意や思考を促す場合がある。白クマ効果などは、その代表的な例として知られている。

本研究では、この心理学的な問題意識を出発点として、LLMに対する概念の抑制指示を検討する。特に、抑制対象と手がかりの意味的な近さに着目し、手がかりの違いが内部表現や生成結果に与える影響を調べる。

## 3. Research Question

> **「Xについて考えないで」という抑制指示の下で、手がかりの意味的距離（近い・遠い）は、LLMの内部表現と最終出力にどのような影響を与えるのか？**

この問いを、次の3つの観点から検証する。

1. **内部表現：** 内部状態から、抑制対象Xに関する情報をどの程度識別できるか。
2. **層別予測：** 各層の状態を語彙空間に投影したとき、Xに関連するトークンの予測がどのように変化するか。
3. **最終出力：** 実際の生成結果において、Xがどの程度出現するか。

## 4. 研究のスタンス

本研究は、「禁止すると逆に考えてしまう」という特定の心理学的現象を証明することを目的としない。抑制・増幅・距離による違い・明確な変化なしのいずれも、信頼できる測定に基づけば研究結果として扱う。

「モデルが考えている」「概念が活性化している」といった曖昧な表現を、そのまま測定結果として扱わない。意識や概念の絶対的な活性量を直接測定するのではなく、観察可能な指標に基づいて議論する。

## 5. 研究で明らかにしたいこと

- 抑制指示によって、対象概念に関する情報の識別可能性は変化するのか。
- 手がかりの意味的距離によって、その変化は異なるのか。
- 内部表現における変化は、実際の生成結果にどの程度反映されるのか。
- 内部表現から識別できる情報と、最終的に出力される情報は一致するのか。
- これらの傾向は、モデルのどの層で観察されるのか。

## 6. 研究の意義

最終出力だけを比較するのではなく、内部表現と層別予測を組み合わせて分析する点に本研究の特徴がある。

また、手がかりと対象概念の意味的距離を変数として導入することで、抑制指示下における情報の識別可能性や出力の変化が、手がかりとの意味的な関係によってどのように異なるのかを検証する。

本研究では、特定の結果を前提とせず、測定の妥当性と再現性を重視しながら、抑制指示・意味的距離・内部表現・最終出力の関係を明らかにする。
