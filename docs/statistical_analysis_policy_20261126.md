# 本実験：統計分析方針・分析と可視化の候補一覧（2026-11-26）

[統合プロトコルv0.95](main_experiment_protocol_v0_95.md)第9・10節の更新メモ。[内部表現の測定方法](internal_representation_measurement_policy_20261126.md)と[回答生成条件](answer_generation_policy_20261126.md)に準拠する。主仮説、概念別分析と混合効果モデルの併用、幅広い探索・可視化を採用する。以下の具体的な推定器・図・検定は実装候補も含み、未実施・v1.0未凍結。

## 1. 主仮説と分析の優先順位

直感的な仮説：抑制指示下で対象概念から意味的に遠いヒントを提示すると、内部表現が相対的に対象概念から離れる。

- H1（Probe）：Avoid X・L24において、Cue–Xコサイン距離 dX が大きいほど、X方向のDecision Function（標準化スコア）が低下する。
- H2（Logit Lens）：同条件・同層で、dX が大きいほど、X/Yのトークン当たり平均対数尤度マージンが低下する。
- 予測方向は負。実際にはX/Y相対指標であり、X単独の概念活性・思考量・純粋な因果効果を測るものではない。
- 両指標の結果を独立に報告し、一致を成功条件としない。Neutral Xとの距離依存性の違い、dY調整、層・カテゴリー・最終出力との関係は副次・探索的分析とする。
- 多数の手法を試し可視化するが、事前に主解析を区別し、都合のよい手法・層・指標だけを主結果に昇格させない。

## 2. 分析単位

100 X（10カテゴリー×10）を目標に、各Xの関連20 Cueを連続距離の主解析に使用する。無関係4 CueとCueなしは別対照。100 Xの場合、関連Cueは2,000文、両条件で4,000関連入力、全体5,000入力、25,000回答（各5回）。

内部スコアは生成直前のユニーク入力を単位とし、5反復を独立な内部測定と数えない。同じCueのAvoid/Neutralは対応データ。出力は入力内に反復がネストし、Cueは概念内にネストする。概念選定は便宜選抜であり全概念母集団への無条件な一般化は避ける。

## 3. A：概念別分析（採用）

| 手法 | 用途 |
|---|---|
| Spearman順位相関 | 概念別の中心指標。単調な距離依存性 |
| Pearson相関 | 直線的な関連の補助評価 |
| 単回帰 | dXの変化量に対するスコアの傾き |
| 偏Spearman相関 | dXとスコアをそれぞれ順位化し、dYの順位への回帰残差の相関 |
| 重回帰 | dX・dYを同時に説明変数とした条件付き傾き |
| Kendallのτ、ロバスト回帰（Theil–Sen等） | 探索・感度分析 |
| 距離帯ごとの要約、平滑曲線 | 非線形性・単調性の探索。20 Cue/概念では複雑なモデルを過適合させない |

各指標の分布、平均、中央値、四分位範囲、負の係数の割合、概念単位の不確実性を集計する。負相関の割合の分母と欠測数を明記し、負の係数と有意な負の係数を区別する。

## 4. B：混合効果モデル（採用）

Probe・Logit Lensについて別々に、Avoid X・L24の関連Cueを対象に、線形混合効果モデルを中心に全体傾向を推定する。概念内中心化したdX・dYを候補とし、概念ランダム切片・dXランダム傾きを基本案とする。

主推定候補：score ~ dX_centered + dY_centered + (1 + dX_centered | concept)

dX単独モデルも併記し、dY調整後の傾きと比較する。主検証はdY調整モデルを中心とする方針だが、具体的な固定効果・ランダム効果構造、推定法、収束時の簡略化順序、信頼区間・検定法は結果を見る前にv1.0で固定する。カテゴリーは10水準の固定効果または層別要約を候補とする。カテゴリーと概念の階層、dX/dY共線性、残差、特異適合、収束を点検する。dY調整は因果的除去ではない。

両条件モデルでは condition × dX を追加し、必要に応じて condition × dY と同一Cueの対応をモデル化する。代替として、同一CueのAvoid−Neutral差を目的変数とする概念別回帰・混合モデルを行う。概念単位のクラスターブートストラップを全体推定・感度分析に用いる候補とする。

## 5. 測定指標別の分析・可視化カタログ

| 測定指標 | 分析候補 | 可視化候補 |
|---|---|---|
| Probe Decision Function / Z-score | Spearman、Pearson、回帰、偏相関、混合モデル、距離帯別要約、条件差 | 散布図＋回帰線、順位残差散布図、距離帯別箱ひげ・バイオリン・点群、概念別フォレスト図、相関ヒストグラム、条件別傾きの対応図 |
| Probe Probability（参考） | 飽和・分布点検、Decision Functionとの対応 | sigmoid対応図、ヒストグラム、距離帯別分布 |
| Probe ROC-AUC・置換検定・通過フラグ | 独立評価の層別性能、通過率、学習文数と性能の関係、測定性能と距離効果の関係（探索） | ROC曲線、学習曲線、置換帰無分布、概念×層ヒートマップ、層別AUC分布、通過数推移 |
| Logit Lens平均対数尤度マージン | Probeと同様の距離分析、条件差、層別分析、トークン数別感度分析 | 散布図、距離帯別箱ひげ、フォレスト図、層×距離帯ヒートマップ、層別推移 |
| Logit Lens合計マージン・初回トークン・候補別値 | 主指標との比較、トークン数・X/Y個別スコアの影響、順位一致 | 平均対合計の散布図、X/Y個別曲線、トークン別ヒートマップ |
| Explicit Mention / Strict Semantic Mention（X/Y別） | 言及率、距離帯・条件別比較、二項ロジスティック混合モデル、内部指標との関連 | 率＋CI、概念別点図、予測確率曲線、明示対意味的同定のクロス表・ヒートマップ |
| Cueへの回答妥当性・形式遵守・曖昧/判定不能 | 評価規則確定後に二項・順序・多項モデル等を選択、条件・距離・内部スコアとの関連 | 積み上げ比率、距離帯別分布、混同行列、保留率 |
| AI評価と人手評価 | 一致率、Cohenのκ等（ラベル型・評価者数に応じる）、クラス別精度・再現率、保留の影響 | 混同行列、不一致例一覧、カテゴリー・条件別一致率 |
| Cue距離・品質（dX/dY） | 相関、共線性、距離帯の間隔・分布、文長・文章タイプの偏り、採択率 | dX×dY散布図、距離帯別点群、ECDF、候補対採択分布、カテゴリー別品質表 |

出力評価の判定基準・保留の扱いは進行中の評価検証に従い、未確定のラベルを正式指標としない。出力の二項混合モデルでは概念・Cueのクラスタリングを考慮し、内部スコアを5回複製して独立観測と扱わない。Probe Probabilityを実際の概念存在確率とは解釈しない。

## 7. 統計的信頼性と報告

- 効果量と95%信頼区間を中心に報告。p値は併記し、効果の大きさや仮説が真である確率と混同しない。
- H1/H2の主要検定を事前指定し、2つの主検定にはHolm補正等を候補とする。副次・探索的な層別、概念別、カテゴリー別の多数検定は検定族を区別し、BH FDR等を候補とする。Probe採択用の検定族は別に扱う。最終規則はv1.0で凍結する。
- 仮説は負方向だが、片側/両側の検定選択は事前固定する（両側を推奨）。有意でないことを同等性や効果不存在とは解釈しない。
- 低性能Probe層は保存・表示し、信頼できる概念指標としての解釈を制限する。相関が定義不能な場合は欠測理由を保存し、ゼロに置換しない。
- 技術的異常・欠測・評価不能・刺激違反の扱いを事前に定める。結果方向や極端な有効値を理由に除外しない。除外前後の感度分析を記録する。
- すべての分析設定・試行・結果（帰無結果・収束失敗を含む）を保存する。多数の可視化は理解・探索・頑健性確認に活用し、選択的報告を避ける。
- 図には実際のN、分母、条件、層、指標、単位、CIの算出法、探索/主解析の区別を明記する。論文掲載図の選択と分析の保存は区別する。
